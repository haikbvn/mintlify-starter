The MIS Production Server runbook covers everything you need to deploy, secure, and maintain a self-hosted MIS server running 24/7 for up to a handful of Windows clients. The stack uses Ubuntu Server 24.04 LTS, Microsoft SQL Server 2025 Express, Tailscale for zero-trust remote access, UFW as the host firewall, and NAS-based backup with automated retention.

## Deployment at a Glance

<Steps>
  <Step title="Prepare Hardware & Install Ubuntu">
    Verify hardware meets the minimum specs, install Ubuntu Server 24.04 LTS, set a static LAN IP, and harden SSH. See [Hardware](/setup/hardware) and [Ubuntu Install](/setup/ubuntu-install).
  </Step>
  <Step title="Install & Secure SQL Server">
    Add the Microsoft package repository, install SQL Server 2025 Express, enable TCP on port 1433, and install `sqlcmd`. See [SQL Server Install](/sql/install).
  </Step>
  <Step title="Connect via Tailscale">
    Install Tailscale, join your tailnet, define tag-based ACL grants, and enable Tailscale SSH for admin access. See [Tailscale Setup](/tailscale/setup).
  </Step>
  <Step title="Configure Backups & Go Live">
    Set up automated nightly backups with NAS copy, run a restore drill, verify RPO/RTO targets, and complete the [Acceptance Checklist](/reference/acceptance-checklist).
  </Step>
</Steps>

<Note>
  SQL Server port 1433 must **never** be port-forwarded to the Internet. All access is via LAN or Tailscale only.
</Note>
